# ps_suicide

Un script de suicidio para FiveM con animación realista.

## Características

- Comando `/suicide` para suicidarse
- Requiere tener una pistola o revólver en la mano
- Animación pausada con opciones de confirmación
- Configuración de armas permitidas

## Instalación

1. Descarga el script
2. Colócalo en tu carpeta `resources`
3. Añade `ensure ps_suicide` a tu `server.cfg`

## Uso

- Escribe `/suicide` en el chat
- Presiona `E` para confirmar
- Presiona `X` para cancelar

## Configuración

Edita `config.lua` para:
- Añadir o quitar armas permitidas
- Personalizar la notificación cuando no tienes arma

## Dependencias

- ESX (para notificaciones)
